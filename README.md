# 我的宇宙

一个温暖手账风格的个人资料站，用来记录喜欢的音乐、电影、生活习惯、近期思考与写给未来自己的话。

## 使用方式

- 直接打开 `index.html` 即可本地浏览。
- 点击右上角“编辑”，可直接修改页面中的虚线文字。
- 编辑内容保存在当前浏览器的 `localStorage`，不会自动上传到 GitHub。
- 使用“导出备份 / 导入备份”可迁移个人内容。

## 数据说明

仓库中的页面仅包含待填写的引导文案，不含虚构的个人信息。浏览器内编辑的内容仅保存在本机；如果希望公开并跨设备同步，需要把确认后的内容写回源码并重新提交。

## 本地预览

```powershell
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 技术

纯 HTML、CSS 和 JavaScript，无构建依赖、无统计追踪、无第三方字体或脚本。
